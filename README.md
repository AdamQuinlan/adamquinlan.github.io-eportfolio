# E-portfolio: Adam Quinlan

An e-portfolio responding to woolloo's Graduate – AI, Data & Product advertisement, for MQBS3010 at Macquarie University.
Built with Astro and published with GitHub Pages.

- Words shared across pages, and LinkedIn links for industry guests, live in `src/data/site.ts`.
- The site address sub-folder is `base` in `astro.config.mjs`. Change it if the repository is renamed.
- Every push to `main` rebuilds the site. Settings → Pages → Source must be GitHub Actions.
